# فروشگاه من — Laravel Marketplace Starter

یک فروشگاه فارسی چنددسته‌ای با Laravel 13 و PostgreSQL برای شروع سریع کسب‌وکار.

## امکانات

- صفحه اصلی، دسته‌بندی‌ها، جستجو و صفحه محصول
- سبد خرید و ثبت سفارش نمونه
- کد تخفیف
- پنل مدیریت با ورود ادمین
- داشبورد آمار فروشگاه
- مدیریت محصولات (افزودن/ویرایش/حذف)
- مدیریت دسته‌بندی‌ها
- مدیریت سفارش‌ها و تغییر وضعیت
- مدیریت مشتریان
- مدیریت کدهای تخفیف
- مدیریت بنرهای صفحه اصلی
- تنظیمات فروشگاه
- نمونه محصولات، دسته‌بندی، بنر و کوپن

## Render

متغیرهای محیطی پیشنهادی:

- `APP_KEY` (یا تولید خودکار در build)
- `APP_URL=https://my-laravel-store.onrender.com`
- `DB_CONNECTION=pgsql`
- `DATABASE_URL=<Internal Database URL from Render>`
- `ADMIN_USERNAME=admin`
- `ADMIN_PASSWORD=<strong secret>`

Dockerfile روی پورت 10000 اجرا می‌شود و در شروع سرویس migration و seed را اجرا می‌کند.

**نکته:** فایل‌سیستم سرویس رایگان Render موقتی است. برای تصویرهای آپلودی واقعی بهتر است بعداً object storage یا فضای پایدار اضافه شود؛ نسخه فعلی از `image_url` برای تصویر محصول استفاده می‌کند.
